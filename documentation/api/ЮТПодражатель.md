# Подражатель (ЮТПодражатель)

## Методы модуля

---

### `Локализация`


Локализация.

**Возвращает**

`Строка` - Возвращает текущую установленную локализацию

Примеры:

```bsl
ТекЛокализация = ЮТПодражатель.Локализация(); // вернет, например, "ru"
```



---

### `УстановитьЛокализацию`


Устанавливает локализацию подражателя.
В дальнейшем используется для получения списка словарей с указанной локализацией.

**Параметры метода**

* `КодЯзыка`
    * `Строка` - Код языка

Примеры:

```bsl
ЮТПодражатель.УстановитьЛокализацию("en");
```



---

### `Люди`


Возвращает подражателя для генерации данных о людях.

**Возвращает**

`CommonModule.ЮТПодражатель_Люди` - Модуль для генерации данных о людях.

Примеры:

```bsl
ЛюдиГенератор = ЮТПодражатель.Люди();
СлучайноеИмя = ЛюдиГенератор.Имя();
```



---

### `Компании`


Возвращает подражателя для генерации данных о компаниях.

**Возвращает**

`CommonModule.ЮТПодражатель_Компании` - Модуль для генерации данных о компаниях.

Примеры:

```bsl
КомпанииГенератор = ЮТПодражатель.Компании();
СлучайноеНазвание = КомпанииГенератор.Название();
```



---

### `Банки`


Возвращает подражателя для генерации данных о банках.

**Возвращает**

`CommonModule.ЮТПодражатель_Банки` - Модуль для генерации данных о банках.

Примеры:

```bsl
БанкиГенератор = ЮТПодражатель.Банки();
СлучайныйБИК = БанкиГенератор.БИК();
```
