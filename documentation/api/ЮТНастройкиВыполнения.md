### `ЗначениеНастройкиТеста`


Возвращает значение произвольной настройки для текущего исполняемого объекта (тест, набор, модуль)

**Параметры метода**

* `ИмяНастройки`
    * `Строка` - Имя настройки, [см. ЮТФабрика.ПараметрыИсполненияТеста](ЮТФабрика#параметрыисполнениятеста)
* `ЗначениеПоУмолчанию`
    * `Произвольный` - Значение по умолчанию
* `СтрогийУровеньИсполнения`
    * `Булево` - Признак, стоит ли проверять наличие настройки у родительских элементов.
      Ложь - По умолчанию, будет выполнен поиск и получение значения для родителей (набор, модуль),
      если значения для текущего элемента не установлено.
      Истина - Получение настройки только для текущего элемента.

**Возвращает**

`Произвольный` - Значение настройки теста

---

### `ГлобальныеНастройкиВыполнения`


Возвращает глобальные настройки выполнения, указанные в файле настроек запуска, объект`settings`

**Возвращает**

`Структура` - Глобальные настройки

---

### `КаталогПроекта`

**Возвращает**

`Строка` - Каталог проекта
