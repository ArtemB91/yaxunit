# Логирование (ЮТЛогирование)

## Методы модуля

---

### `Отладка`


Выводит отладочное сообщение

**Параметры метода**

* `Сообщение`
    * `Строка` - Сообщение

---

### `Информация`


Выводит информационное сообщение

**Параметры метода**

* `Сообщение`
    * `Строка` - Сообщение

---

### `Предостережение`


Выводит предупреждение

**Параметры метода**

* `Сообщение`
    * `Строка` - Сообщение

---

### `Ошибка`


Выводит сообщение об ошибке

**Параметры метода**

* `Сообщение`
    * `Строка` - Сообщение
* `Ошибка`
    * `ИнформацияОбОшибке` - 

---

### `Включено`


Возвращает признак, что логирование включено.

**Возвращает**

`Булево` - Включено
