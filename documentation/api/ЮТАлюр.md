---

### `УровниСерьезности`


Уровни критичности Allure

**Возвращает**


<details><summary>

`Структура` - Уровни серьезности:

</summary>

* `Тривиальный` - `Строка` - 
* `Незначительный` - `Строка` - 
* `Нормальный` - `Строка` - 
* `Критический` - `Строка` - 
* `Блокер` - `Строка` - 
* `Trivial` - `Строка` - 
* `Minor` - `Строка` - 
* `Normal` - `Строка` - 
* `Critical` - `Строка` - 
* `Blocker` - `Строка` - 

</details>
