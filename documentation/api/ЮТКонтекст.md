# Контекст (ЮТКонтекст)

## Методы модуля

---

### `ЗначениеКонтекста`


ЗначениеКонтекста
Возвращает значение вложенного контекста, вложенного реквизита контекста

**Параметры метода**

* `ИмяРеквизита`
    * `Строка` - Имя реквизита/вложенного контекста

**Возвращает**

`Структура` - Значение реквизита/вложенного контекста

---

### `УстановитьЗначениеКонтекста`


УстановитьЗначениеКонтекста
Устанавливает значение вложенного контекста, вложенного реквизита контекста

**Параметры метода**

* `ИмяРеквизита`
    * `Строка` - Имя реквизита/вложенного контекста
* `Значение`
    * `Произвольный` - Новое значение реквизита/вложенного контекста

---
