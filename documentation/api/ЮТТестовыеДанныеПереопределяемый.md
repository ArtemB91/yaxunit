# ЮТТестовые данные переопределяемый (ЮТТестовыеДанныеПереопределяемый)

## Методы модуля

---

### `КодИнициализацииПоТипам`


Процедура - Код инициализации по типам

**Параметры метода**

* `КодИнициализации`
    * `Соответствие` - тип данных и код для его установки
      Пример кода:
      КодИнициализации.Вставить(Тип("СправочникСсылка.ПодразделенияОрганизаций"), "озТестовыеДанные.ПоздразделениеОрганизации(""%1"", Организация); // %1");

---

### `ПорядокСортировкиПеременных`


Функция - Порядок сортировки переменных

**Возвращает**

`Соответствие` - типы значений и их порядок для сортировки

Примеры:

```bsl
Порядок.Вставить(Тип("СправочникСсылка.Организации"), 0);
Порядок.Вставить(Тип("СправочникСсылка.ПодразделенияОрганизаций"), 1);
Порядок.Вставить(Тип("СправочникСсылка.Валюты"), 2);
Порядок.Вставить(Тип("СправочникСсылка.Контрагенты"), 3);
Порядок.Вставить(Тип("СправочникСсылка.ДоговорыКонтрагентов"), 4);
```



---

### `ПостоянныеДанные`


Функция - Постоянные данные

**Возвращает**

`Соответствие` - Данные которые являются постоянными для системы, и их можно искать по идентификатору указаном в значении

Примеры:

```bsl
ПостоянныеДанные.Вставить(Тип("СправочникСсылка.Валюты"), "Код");
ПостоянныеДанные.Вставить(Тип("СправочникСсылка.КлассификаторЕдиницИзмерения"), "Наименование");
```
