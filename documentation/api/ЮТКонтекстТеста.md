# Контекст теста (ЮТКонтекстТеста)

## Методы модуля

---

### `Значение`


Возвращает значение контекста

**Параметры метода**

* `ИмяЗначения`
    * `Строка` - 

**Возвращает**

`Произвольный` - Сохраненное в контексте значение

---

### `УстановитьЗначение`


Установить значение.
Устанавливает значение в контекст тестов.
Установка происходит в соответствии с уровнем исполнения

**Параметры метода**

* `ИмяЗначения`
    * `Строка` - 
* `Значение`
    * `Произвольный` - 

---

### `ТекущийКонтекст`


Текущий контекст исполнения теста

**Возвращает**

`Неопределено` - Текущий контекст
