# Исключения (ЮТИсключения)

## Методы модуля

---

### `НекорректныеПараметрыМетода`


Формирует текст исключения о некорректных параметрах вызова метода

**Параметры метода**

* `ИмяМетода`
    * `Строка` - 
* `Пояснение`
    * `Строка` - 

**Возвращает**

`Строка` - Текст исключения

---

### `НеподдерживаемыйПараметрМетода`


Формирует текст исключения о неподдерживаемом значении параметра вызова метода

**Параметры метода**

* `ИмяМетода`
    * `Строка` - 
* `ЗначениеПараметра`
    * `Произвольный` - 

**Возвращает**

`Строка` - Текст исключения

---

### `МетодНеДоступен`


Формирует текст исключения о недоступности метода в указанном контексте

**Параметры метода**

* `ИмяМетода`
    * `Строка` - 
* `ИмяКонтекста`
    * `Строка` - 

**Возвращает**

`Строка` - Текст исключения
