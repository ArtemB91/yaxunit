### `КоличествоВызовов`


Начинает утверждение для проверки количества вызовов метода.

Устанавливает параметры поиска вызовов.

**Параметры метода**

* `ИмяМетода`
    * `Строка` - Имя метода проверяемого объекта
    * `Произвольный` - Вызов метода проверяемого объекта
* `ПараметрыВызова`
    * `Массив из Произвольный` - Параметры вызова метода проверяемого объекта, необходим при указании имени метода

**Возвращает**

`ОбщийМодуль` - [см. МокитоПроверки](МокитоПроверки)

---

### `Вызовы`


Возвращает информацию о вызовах метода.

**Параметры метода**

* `ИмяМетода`
    * `Строка` - Имя метода проверяемого объекта
    * `Произвольный` - Вызов метода проверяемого объекта
* `ПараметрыВызова`
    * `Массив из Произвольный` - Параметры вызова метода проверяемого объекта, необходим при указании имени метода

**Возвращает**

`Массив из см. МокитоСлужебный.СтруктураВызоваМетода` - Вызовы метода

---

### `Равно`


Проверяет вызовы метода ([см. КоличествоВызовов](#количествовызовов)).
Их количество должно быть равно переданному значение, иначе будет выброшено исключение.

**Параметры метода**

* `Количество`
    * `Число` - Ожидаемое количество вызовов
* `Описание`
    * `Строка` - Описание проверки, необходимо для идентификации упавшей проверки

**Возвращает**

`ОбщийМодуль` - [см. МокитоПроверки](МокитоПроверки)
