# Регистрация ошибок (ЮТРегистрацияОшибок)

## Методы модуля

---

### `ДобавитьПояснениеОшибки`


Добавляет пояснение возникшей ошибки, которое будет добавлено в отчет.
Используется перед выбросом исключения, чтобы добавить полезной информации об ошибке, но при этом не ломать стек.

**Параметры метода**

* `Пояснение`
    * `Строка` - Пояснение

---

### `ПредставлениеОшибки`


Фрмирует сообщение об ошибки.

**Параметры метода**

* `Описание`
    * `Строка` - Префикс текста ошибки
* `Ошибка`
    * `Строка` - Ошибка
    * `ИнформацияОбОшибке` - Ошибка
